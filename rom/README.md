# ROM directory

- `ti83plus.rom` - optional 512KB dump from a TI-83 Plus you own (not redistributed here)
- `pipeline.rom` - generated by `lua tools/build_pipeline_rom.lua` (Z80 text-screen test)
- `synth.rom` - generated by `lua tools/make_synth_rom.lua` for keypad bring-up tests

## Flash layout (512KB / 32x16KB)

| Pages | Role |
|------|------|
| 0-7 | OS |
| **8-21 (`0x08`-`0x15`)** | **User archive / Flash Apps** |
| 22-30 | OS / reserved |
| 31 | Boot page |

## Installing software (no TI-Link)

```bash
# Desktop: bake Flash Apps into a ROM image
lua tools/inject_8xk.lua rom/ti83plus.rom MyApp.8xk -o rom/ti83plus_apps.rom
```

```text
# ComputerCraft
test --help
test --loadapp MyApp.8xk          # optional: bake Flash App before boot
test                              # control panel on the computer screen:
                                  #   click .8xk / .8xp / .8xg to load
                                  #   SWAP monitors, status bar shows MHz
```

- `.8xk` apps go into archive pages (high -> low); before boot via `--loadapp`, or click in the panel.
- `.8xp` programs install into RAM/VAT when clicked after the OS homescreen is up.
- `.8xg` groups unpack contained programs into PRGM (same VAT path as `.8xp`).
